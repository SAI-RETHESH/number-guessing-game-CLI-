# number-guessing-game-CLI-
This is a game where user have to guess the number based on what level they have chosen.
It is a CLI-based game, so you need to use the command line to interact with the game. The game will work as follows:

When the game starts, it will display a welcome message along with the rules of the game.

The computer will randomly select a number between 1 and 100.

User will select the difficulty level (easy, medium, hard) which will determine the number of chances they get to guess the number.

The user should be able to enter their guess.

If the user's guess is correct, the game will display a congratulatory message along with the number of attempts it took to guess the number.

If the user's guess is incorrect, the game will display a message indicating whether the number is greater or less than the user's guess.

The game will end when the user guesses the correct number or runs out of chances.
